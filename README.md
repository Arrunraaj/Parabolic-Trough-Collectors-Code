# Parabolic Trough Collectors for Industrial Process Heating

A solar thermal energy study investigating the integration of **Parabolic Trough Collectors (PTC)** into a textile manufacturing facility to reduce wood-fuel consumption in the stenter heating process.

## Project Overview

The existing textile process uses a wood-fired boiler to provide heat at approximately **240°C** to a stenter machine. This project evaluates replacing part of the boiler heat with solar thermal energy using **Therminol VP-1** as the heat-transfer fluid.

The study covers:

* PTC solar-field modelling
* Collector area sizing and optimization
* Solar-field efficiency calculation
* Thermal energy storage
* Wood-fuel savings
* CO₂ emission reduction
* Economic and payback analysis

## Key Results

| Parameter              |                Result |
| ---------------------- | --------------------: |
| Required PTC area      |          **4,480 m²** |
| Solar-field efficiency |             **89.3%** |
| Approx. collectors     |           **19 SCAs** |
| Thermal storage        | **16.39 m³ (1 hour)** |
| Wood savings           |   **524 tonnes/year** |
| CO₂ reduction          |  **~917 tonnes/year** |
| Estimated investment   |       **₹6.72 crore** |
| Annual savings         |   **₹71.8 lakh/year** |
| Simple payback         |         **~38 years** |

## Technology

**Solar radiation → Parabolic Trough Collector → Therminol VP-1 → Thermal Storage/Heat Exchanger → Stenter Machine**

The project demonstrates the potential of **Concentrated Solar Thermal Energy for industrial process heating**, particularly for high-temperature textile applications.
